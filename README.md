**当前版本：** `v0.1.3`

SIXLV BALATRO PACK 是一个以《Balatro》原版美术与玩法为基础的内容及平衡调整模组。

模组新增三副牌组、两级高难度注，并调整部分原版小丑牌、优惠券与高难度规则，目标是在保留原版体验的同时提供更多可用构筑和不同的开局方式。

当前版本仍在持续测试与调整，现有数值不代表最终版本。

## 新增难度

### 澳金注

在金注之后加入澳金注。商店中的兼容小丑有 `30%` 概率获得“肥大”标签。

- 占据两个小丑栏位。
- 购买价格翻倍，出售价格不随之翻倍。
- 支持的筹码与倍率效果额外触发一次。
- 乘倍效果采用线性翻倍，例如 `X3` 变为 `X6`。
- 回合结束金钱收益翻倍。
- 肥大与租赁共存时，每回合共扣除 `$6`。
- 肥大与易腐共存时，每回合减少 `2` 点易腐计数。
- 肥大不能与负片同时存在。
- 部分复用类、特殊功能类和传奇小丑不会获得肥大。
- 乌合之众、审判、怨灵与灵魂生成的小丑牌不会获得标签。
- 安卡和隐形小丑生成的副本会保留被复制小丑的标签；栏位不足时按照“被挤压”规则处理。

### 小丑注

小丑注继承澳金注的全部规则，并进一步提高各底注所需的基础分数。

| 底注 | 基础分数 |
| ---: | ---: |
| 1 | 300 |
| 2 | 1,100 |
| 3 | 3,900 |
| 4 | 12,000 |
| 5 | 37,000 |
| 6 | 100,000 |
| 7 | 200,000 |
| 8 | 400,000 |

底注 9 及之后会继续提高分数要求。

## 新增牌组

### 占卜师牌组

以强化塔罗牌为核心。以下牌组规则与塔罗牌调整只在占卜师牌组中生效。

#### 牌组规则

- 商店卡牌基础权重调整为：小丑牌 `20`、塔罗牌 `4`、星球牌 `0`。
- 标准卡牌包的出现权重提高至原版的 `1.5` 倍。
- 幻灵包的出现权重提高至原版的 `2` 倍。
- 正常游戏过程中不再生成星球牌、天体包、黑洞或恍惚。
- 标准卡牌包及其他随机蜡封来源不再生成蓝色蜡封。
- 证书生成的卡牌只会获得红色、金色或紫色蜡封，三者概率均为 `1/3`。

### 冻洋牌组

- 每回合 `+2` 次出牌。
- 初始弃牌次数为 `0`。
- 每 `2` 次剩余出牌获得 `$1`；不足 `2` 次的余数不结算。

### 炼狱牌组

- 手牌上限 `+4`。
- 初始获得贪婪小丑、色欲小丑、愤怒小丑与暴食小丑。
- 游戏底注 `+2`。
- 本赛局第一手出牌所形成的牌型永久提升 `2` 级，并按提升后的等级计分。

## 安装要求

- Steam 版《Balatro》
- [Lovely](https://github.com/ethangreen-dev/lovely-injector)
- [Steamodded](https://github.com/Steamodded/smods) `1.0.0~`

## 安装方法

1. 安装 Lovely 与 Steamodded。
2. 下载并解压发布包。
3. 将 `SIXLVBalatroPack` 文件夹放入：

```text
%AppData%\Balatro\Mods\
```

4. 启动游戏，并在模组列表中确认 **SIXLV BALATRO PACK** 已加载。
